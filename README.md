# مِعيار | Miyār

واجهة ثنائية اللغة لإدارة الامتحانات ومراجعة التقييم الأكاديمي. تعمل بالعربية والإنجليزية، وتضبط اتجاه العرض تلقائيًا حسب اللغة.

## التشغيل

يمكن فتح `index.html` مباشرة، أو تشغيل خادم ملفات محلي:

```powershell
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الصفحات

- صفحة تعريفية بالمشروع (Landing page) هي نقطة الدخول الافتراضية
- لوحة التحكم والامتحانات
- واجهتا تسجيل الدخول وإنشاء الحساب
- إنشاء امتحان ومعايير الإجابة
- رفع الأوراق ومراجعة الملفات المختارة
- مراجعة درجات الإجابات
- النتائج وتصدير CSV والطباعة إلى PDF
- الإعدادات ودليل الاستخدام

## حدود النسخة الحالية

هذه واجهة أمامية مستقلة ببيانات توضيحية، وتحفظ بيانات النماذج الوصفية في `localStorage`. واجهتا الدخول وإنشاء الحساب لا تنشئان جلسات فعلية بعد. شاشة الرفع تتحقق من نوع الملف وحجمه، لكنها لا ترسل محتوى الملفات إلى الخادم. يلزم ربطها بمسار الرفع الفعلي في FastAPI وخدمة OCR والمصادقة عند توفر عقد الطلب والاستجابة. بيانات الامتحانات والنتائج المعروضة حاليًا أمثلة للواجهة وليست سجلات طلاب فعلية.
