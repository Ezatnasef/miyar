# مِعيار | Miyār

**منصة أكاديمية لإدارة تصحيح الإجابات القصيرة والمقالية ومراجعة النتائج.**

مِعيار نموذج أولي لواجهة ويب تساعد أعضاء هيئة التدريس على تنظيم الامتحانات، إعداد الأسئلة ومعايير الإجابة، متابعة أعمال التصحيح، ومراجعة الدرجات قبل اعتمادها. صُممت الواجهة بالعربية والإنجليزية، مع دعم اتجاهي العرض من اليمين إلى اليسار (RTL) ومن اليسار إلى اليمين (LTR).

> **حالة المشروع:** الواجهة الأمامية جاهزة للتجربة. البيانات الحالية توضيحية ومحلية؛ رفع الملفات إلى الخادم، واستخراج النصوص فعليًا عبر OCR، والتقييم الآلي، والمصادقة، وقاعدة البيانات لم تُربط بعد.

## نظرة عامة

تعالج المنصة احتياجًا أكاديميًا يتمثل في تنظيم تقييم الإجابات المفتوحة، حيث قد تعبّر إجابات الطلاب عن الفكرة الصحيحة بصياغات مختلفة. لذلك تعرض التجربة معايير السؤال والإجابة ودرجة قابلة للمراجعة، مع إبقاء مراجعة المدرّس واعتماده جزءًا أساسيًا من سير العمل.

تتضمن الرؤية المستقبلية استقبال أوراق الامتحان، واستخراج محتواها، ومقارنة الإجابات بمعايير التصحيح، ثم إعداد النتائج والتقارير. هذه الوظائف موضحة في تصميم الواجهة، لكنها لا تُنفذ آليًا في النسخة الحالية.

## الوظائف والصفحات

| الصفحة | المسار | الوظيفة الحالية |
|---|---|---|
| الصفحة التعريفية | `#landing` | تعريف بالمشروع، شرح المزايا وسير العمل، وروابط استكشاف المنصة |
| لوحة التحكم | `#dashboard` | ملخص إحصائي ونشاط حديث باستخدام بيانات توضيحية |
| الامتحانات | `#exams` | استعراض الامتحانات والبحث والتصفية حسب الحالة والمقرر |
| إنشاء امتحان | `#create` | حفظ بيانات الامتحان وأسئلته وإجاباته النموذجية محليًا |
| رفع الأوراق | `#upload` | اختيار ملفات PDF أو JPG أو PNG والتحقق من النوع والحجم؛ لا يتم إرسالها إلى الخادم |
| مراجعة التصحيح | `#grading` | تجربة مراجعة توضيحية تسمح بتعديل الدرجة وإضافة ملاحظة |
| النتائج والتقارير | `#results` | عرض نتائج توضيحية وتنزيل CSV أو فتح نافذة الطباعة للحفظ بصيغة PDF |
| الإعدادات | `#settings` | حفظ تفضيلات الملف الشخصي واللغة محليًا |
| دليل الاستخدام | `#guide` | عرض خطوات إعداد الامتحان ورفع الأوراق ومراجعة النتائج |
| تسجيل الدخول وإنشاء الحساب | `#login` و`#signup` | واجهات عرض فقط؛ لا تنشئ جلسة دخول أو حسابًا فعليًا |

## التقنيات والبنية

- **HTML5:** هيكل الصفحات والنماذج والعناصر الدلالية.
- **CSS3:** الهوية المرئية بالأزرق الملكي والرمادي الفاتح، تخطيطات متجاوبة، ودعم RTL/LTR.
- **JavaScript:** عرض الصفحات والتنقل بينها، الترجمة، تفاعلات النماذج، البحث والتصفية، وحفظ بيانات النموذج الأولي.
- **التبعيات:** لا توجد حزم npm مطلوبة؛ الواجهة مبنية باستخدام تقنيات المتصفح الأساسية.
- **التخزين الحالي:** `localStorage` في المتصفح للغة وبعض بيانات الامتحانات والمراجعات والتفضيلات.

## التشغيل محليًا

يتطلب التشغيل Python 3 لتوفير خادم ملفات محلي. من مجلد المشروع شغّل:

```powershell
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

لإيقاف الخادم، استخدم `Ctrl+C` في نافذة الطرفية.

يمكن فتح `index.html` مباشرة في المتصفح لبعض المعاينات، لكن يوصى بالخادم المحلي لتجنّب قيود المتصفح على الملفات المحلية.

## تخزين البيانات والتصدير

- تُحفظ بيانات النموذج الأولي في متصفح المستخدم فقط؛ لا توجد قاعدة بيانات متصلة.
- بيانات لوحة التحكم وبيانات الطلاب والنتائج المعروضة أمثلة للتوضيح وليست سجلات حقيقية.
- اختيار ملف في صفحة الرفع لا يرفع محتواه. تحفظ الواجهة أسماء الملفات المختارة ضمن قائمة محلية مرتبطة بالامتحان.
- تنزيل CSV يُنشئ ملفًا من بيانات النتائج التوضيحية الحالية.
- خيار PDF يفتح نافذة طباعة المتصفح؛ يمكن للمستخدم اختيار الطباعة أو الحفظ بصيغة PDF.
- حذف بيانات الموقع من إعدادات المتصفح يحذف البيانات المحلية المحفوظة.

## حالة التكامل مع الخادم

| المكوّن | الحالة |
|---|---|
| واجهة FastAPI | لم تُضمّن في هذا المستودع الأمامي |
| رفع الملفات | اختيار محلي والتحقق من النوع والحجم؛ لا يوجد طلب HTTP |
| OCR | غير موصول |
| التقييم الآلي أو النموذج | غير موصول؛ الدرجات المعروضة للتوضيح |
| المصادقة | تصميم واجهة فقط |
| قاعدة البيانات | غير موصولة |
| التصدير | CSV توضيحي، والطباعة عبر المتصفح |

قبل الاستخدام ببيانات حقيقية، يلزم تحديد عقد API واضح لمسارات المصادقة والامتحانات ورفع الملفات ونتائج OCR، وربط الواجهة بخادم موثوق، وإعداد سياسة مناسبة لحماية أوراق الطلاب والبيانات الشخصية.

## التحقق والتجربة

- فُحصت صياغة JavaScript باستخدام `node --check app.js`.
- جُرّبت الصفحات في المتصفح بالعربية والإنجليزية مع التحقق من تبديل اتجاه العرض.
- جُرّبت واجهة إنشاء امتحان متعدد الأسئلة، وحفظ مراجعة، وقائمة ملفات محلية.
- جُرّبت أبعاد الهاتف والتنقل إلى لوحة التحكم.

لا يحتوي المستودع حاليًا على مجموعة اختبارات آلية أو إعداد بناء؛ فهو تطبيق واجهة ثابتة دون حزم خارجية.
